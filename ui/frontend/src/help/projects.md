# Projects

A project holds its own resources and API tokens, like a project in the
Hetzner Cloud Console. Projects can only be managed while the cloud runs.

- **Create project** adds a project.
- Open a project to see its tokens. **Create token** shows the new token
  once; copy it right away, it is never shown again.
- Deleting a project deletes all its resources; type its name to confirm.
