# Projects

A project holds its own resources and API tokens, like a project in the
Hetzner Cloud Console. Projects can only be managed while the cloud runs.

- **Create project** adds a project.
- Click a project to see its tokens. **Create token** asks for a name and
  whether the token is **Read only**, then shows the token once; copy it
  right away, it is never shown again.
- **Revoke** in a token's row menu (`…`) cuts off the clients that use it.
- **Delete** in a project's row menu deletes the project with all its
  resources; type its name to confirm.
