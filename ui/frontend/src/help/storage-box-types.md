# Storage Box Types

The storage box types your projects can use: the shipped catalog and your
own types; the column **Source** tells them apart. The list shows while
the cloud is stopped too. The catalog comes with the release and has no
update button. When your own types cannot be used, a banner above the
list says why.

- **Add storage box type** opens a form for your own type: name,
  description, size (in MiB, GiB or TiB), snapshot limit, automatic
  snapshot limit and subaccounts limit. Under **Locations**, **All
  locations** (ticked by default) offers the type everywhere; untick it
  and tick at least one location to offer it only there.
- **Edit** in an own type's row menu (`…`) opens the same form filled in
  with its values; the name stays fixed, **Save** applies the changes.
  Catalog types cannot be edited.
- **Remove** in an own type's row menu (`…`) removes it after a
  confirmation. Existing storage boxes of that type keep running; new
  boxes cannot use it.
