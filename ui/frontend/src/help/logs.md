# Logs

The log of the HLab service: the last 1000 lines, then new lines as they
are written, while the cloud runs and while it is stopped.

- **Level** hides the lines below the level you choose.
- **Follow** keeps the list scrolled to the newest line. Turning it off
  stops new lines; turning it on again reloads the last 1000 lines.
- The search field searches the whole log, older files included, when
  you press Enter or stop typing. It shows the matching lines newest
  first, at most 1000, with the matched text highlighted, and turns
  **Follow** off. Clear the field to return to the live log.
- **Load older lines** adds the 1000 lines before the oldest one shown.
  It is disabled once the start of the oldest log file is reached.
