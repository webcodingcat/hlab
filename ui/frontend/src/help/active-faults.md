# Active faults

The faults that are active in all projects, each with the project it
belongs to. You reach this page through the pill "N faults active" in the
top bar, which shows while any fault is active. The list refreshes every
5 seconds and needs the cloud to run.

- The list has the same columns as a project's **Faults**, with a
  **Project** column first; the project's name opens its Faults page,
  where you also create faults.
- **End** in the row menu (`…`) ends that fault at once.
- **End all** ends every fault of every project after you confirm. The
  tray menu's **End all faults** does the same without asking.

With no fault active the page reads "No faults are active." and the pill
in the top bar disappears.
