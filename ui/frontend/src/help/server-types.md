# Server Types

The server types your projects can use: the shipped catalog and your own
types, as the cloud merges them. The list shows while the cloud is stopped
too.

- **Add server type** adds your own type with a name, cores, memory, disk,
  CPU type and the locations it is offered in (empty means all).
- **Remove** in an own type's row menu (`…`) removes it. Existing servers
  of that type keep running; new servers cannot use it.
- **Update from Hetzner** fetches the current server types with a Hetzner
  token, which is never stored. It needs the running cloud.
