# Server Types

The server types your projects can use: the shipped catalog and your own
types, as the cloud merges them. The list shows while the cloud is stopped
too.

- Add your own type with a name, cores, memory, disk and CPU type.
- Removing an own type keeps existing servers of that type running.
- **Update from Hetzner** fetches the current catalog with a Hetzner token,
  which is never stored. It needs the running cloud.
