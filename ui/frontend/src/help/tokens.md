# API tokens

The API tokens of this project. Clients such as hcloud, OpenTofu and
Ansible use a token to reach the project's API.

- **Create token** asks for a name and whether the token is **Read only**,
  then shows the token once; copy it right away, it is never shown again.
- **Revoke** in a token's row menu (`…`) cuts off the clients that use it.
