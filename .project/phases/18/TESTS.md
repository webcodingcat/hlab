# Phase 18: test map

Paths under `/hetzner/v1` go through `apitest.Env.Do` with the full path
(validated against `hetzner.spec.json`); storage box tests set
`cat.StorageBoxTypes = apitest.StorageBoxTypes(t)` and keep actions running
with a gate in `storageboxes.Deps.Apply` where a row needs that.
