# Phase 08 test map

Every subtest name carries its requirement ID and sits in a group named
after its component.

Unit tests of the resource modules go through `apitest`, which validates
responses against the frozen OpenAPI description (patched for
`assignee_type` "load_balancer", PLAN D7), with a recording agent push:
- `TestLoadBalancers` lives in internal/resources/loadbalancers/loadbalancers_test.go (shared helper `newEnv`) and also runs the rows of network_test.go, services_test.go, targets_test.go, status_test.go, dnsptr_test.go and contribute_test.go.
- `TestCertificates` lives in internal/resources/certificates/certificates_test.go and also runs managed_test.go. Managed tests use a fake `Issuer` backed by a `ca.CA` in `t.TempDir()`, and a fake clock.

Other components:
- Agent rows run in `TestAgent`: the group is in internal/agent/metadata_test.go, the rows in haproxy_test.go. They are pure Go and need no HAProxy binary.
- Host rows run in `TestHostNet` (internal/hostnet/windows) with an injected command runner. No test touches the real trust store or WSL.
- `TestCA` runs in a temp folder.

End-to-end subtests live under `TestE2E` in `test/e2e` (build tag `e2e`, registered in e2e_test.go, run in parallel) and share the fixture `sharedLB`:
- a per-run zone under `.test`
- a network, and two servers in it that serve their hostname over HTTP on port 80
- one LB in the network with private targets: tcp 8080 to 80; http 8000 to 80 sticky; https 443 with a managed certificate for `www.<zone>` and `redirect_http`

Rules for the e2e tests:
- Both servers also serve their hostname on port 8081 from a second web server. LB-05 uses its own tcp service 8081 to 8081 and stops and starts only that web server, so LB-02/03/04 stay undisturbed.
- CERT-04 switches trust on and off and restores the off state in `t.Cleanup`. LB-04 never depends on trust: it uses `curl --cacert` with the exported CA in WSL2.
- Host requests use `curl.exe`; WSL2 requests use `curl` in the harness distro.
- Every wait is a condition with a deadline.
