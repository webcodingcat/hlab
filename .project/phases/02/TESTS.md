# Phase 02 test map

Subtest names carry the requirement ID (`t.Run("API-09", ...)`), in a group
named after the component, as in phase 01. Every unit test goes through
`apitest`, which validates each response against the frozen OpenAPI
description (API-10). End-to-end subtests live under `TestE2E` in
`test/e2e` (build tag `e2e`) and share the phase 01 harness plus the WSL2
distro, the temporary key in it, OpenTofu and Ansible (plan 02-05); the
client rows reuse the shared server. Client rows are named
`CLI-0n/<resource type>`; CLI-02 and CLI-03 stay open until phase 13.
