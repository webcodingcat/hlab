## hcloud v1.70.2 requests

- `server create`: `GET /server_types?name=<n>` (reads `architecture`),
  `GET /images?name=<n>&architecture=x86&include_deprecated=true` (no `type`
  filter), `GET /ssh_keys?name=<n>` (if empty: local file and
  `?fingerprint=<md5>`), `GET /locations?name=<n>`, `POST /servers`
  (`server_type`, `image`, `location` as name or ID string, `ssh_keys` IDs,
  `start_after_create`), wait on `action` + `next_actions`, then
  `GET /servers/{id}`. Numeric arguments use `/x/{id}`.
- Waiting: only `GET /actions?id=1&id=2&sort=status&sort=id` every 500 ms,
  never `/actions/{id}`; it fails with "actions not found" unless every
  requested ID is returned; only `running` actions are polled. Always send
  `action` as an object and `next_actions` as `[]`.
- `ssh-key create`: `POST /ssh_keys {name, public_key, labels?}`, key not trimmed.
- `server describe`/`list`/`ip`/`delete`: `GET /servers?name=<n>` (list: `GET
  /servers`); `DELETE /servers/{id}` returns `action` and is waited on.
  Unguarded: `server.location` (full object) and `server_type.locations`
  (must contain the server's location); `public_net.ipv4.ip` and
  `public_net.ipv6.ip` (`2001:db8:...::/64`) must be present; `image`, `iso`,
  `placement_group` may be null. Send `meta.pagination` on every list.
- Server schema (hcloud-go v2.53.0) has no `datacenter`; it was removed from
  servers and primary IPs on 2026-07-01.

## Catalog facts

- Server type fields: `id, name, description, category, cores, memory, disk,
  storage_type, cpu_type, architecture, prices[], locations[]` with
  `locations[] = {id, name, available, recommended, deprecation}`; `deprecated`
  removed 2026-11-02. cx22/cpx11..51 are gone since 2026-01-01; current small
  x86 type: `cx23`. The e2e tests use `cx23` in `fsn1`.
- `/datacenters`, `/datacenters/{id}`: removed 2026-10-01, answer 410 Gone;
  the frozen description marks them deprecated without a 410 entry, so the
  body is the generic error object (code unconfirmed: `deprecated_api_endpoint`).
- Location fields: `id, name, description, country, city, latitude,
  longitude, network_zone`; fsn1/nbg1/hel1 eu-central, ash us-east, hil
  us-west, sin ap-southeast; generated by `task catalog` from the real API.
