# Phase 03 test map

Subtest names carry the requirement ID, in a group named after the
component. Unit tests of the servers module go through `apitest` (responses
validated against the frozen OpenAPI description) with
`platformtest.Fake` and a fake clock; time limits use short values. End-to-end
subtests live under `TestE2E` in `test/e2e` (build tag `e2e`) and share the
phase 01/02 harness. Rows that power off, rebuild or change a server each
create their own server of the smallest x86 type and delete it; the rest use
the shared server. No fixed waits: every wait is a condition with a deadline.
