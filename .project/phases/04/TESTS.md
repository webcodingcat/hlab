# Phase 04 test map

Subtest names carry the requirement ID, in a group named after the
component. Unit tests of resource modules go through `apitest` (responses
validated against the frozen OpenAPI description) with `platformtest.Fake`,
a fake clock and fake image store, appliance job and agent status; time
limits use short values. New test files of a package with an existing group
register their subtests in it: `TestServers` (internal/resources/servers/
servers_test.go) runs the rows of snapshot_test.go, backup_test.go,
rescue_test.go, iso_test.go and vendordata_test.go; `TestAgent`
(internal/agent/metadata_test.go) runs the row of jobs_test.go. End-to-end
subtests live under `TestE2E` in `test/e2e` (build tag `e2e`, registered in
e2e_test.go) and share the harness; rows that reset, rebuild or attach
create their own servers of the smallest x86 type through `ownServer` and
delete them, volumes included. No fixed waits: every wait is a condition
with a deadline.
