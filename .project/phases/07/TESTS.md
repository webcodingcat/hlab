# Phase 07 test map

Subtest names carry the requirement ID, in a group named after the
component. Unit tests of the zones, primary IPs and floating IPs modules go
through `apitest` (responses validated against the frozen OpenAPI
description) with a recording agent push and, for zones, a recording
`SetZones` and a fake `ShadowWatch`. The group `TestZones` lives in
internal/resources/zones/zones_test.go and also runs the rows of
rrsets_test.go, zonefile_test.go and shadow_test.go. The group
`TestDNSZone` lives in internal/dnszone/dnszone_test.go and also runs
zonefile_test.go. Agent rows run in `TestAgent` (group in
internal/agent/metadata_test.go, rows in dns_test.go); their upstream is a
local miekg/dns server on 127.0.0.1, and queries go to the handler
directly. Server rows for RDNS-01 run in `TestPrimaryIPs` with the servers
module mounted beside it and `srv.SetDNSPtrs(pips)`.

End-to-end subtests live under `TestE2E` in `test/e2e` (build tag `e2e`,
registered in e2e_test.go, run in parallel). DNS-02 and RDNS-02 share the
shared server (`sharedServer`). Zones use a per-run name under `.test`
(never shadowing). Host lookups use `Resolve-DnsName`, never nslookup (E5).
WSL2 lookups use `getent hosts` in the harness distro. Server lookups use
`getent hosts` over SSH. Every wait is a condition with a deadline.
